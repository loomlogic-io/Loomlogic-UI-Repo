# Security policy

## Supported versions

LoomLogic UI is pre-1.0. Security fixes are applied to the current default branch. Older commits and unpublished package snapshots are not maintained as separate release lines.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret. Use GitHub's private vulnerability reporting for this repository instead.

Include the affected file or package, reproduction steps, impact, and any suggested mitigation. Please avoid accessing data that is not yours, disrupting services, or publicly disclosing the issue before it has been reviewed.

The repository owner will acknowledge a complete report as soon as practical, assess severity, and coordinate remediation and disclosure when needed.

## Scope

Reports may cover source code, build and release workflows, dependency supply-chain risks, the registry, and the LoomLogic UI skill. The UI Lab is a local, Git-backed preview application and intentionally has no authentication, database, CMS, or package-publishing capability.
