# Registry

The registry is the Git-backed catalog source of truth for UI Lab. Update code and metadata in the same review.

- `components/`: primitives and package exports
- `kits/`: LL Core and shallow derived-kit definitions
- `patterns/`: composed product patterns
- `pages/`: full-page references

Lifecycle approval and Codex-skill promotion are deliberately separate fields. See [the promotion flow](../docs/promotion-flow.md).
