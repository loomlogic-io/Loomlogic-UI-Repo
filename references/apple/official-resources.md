# Official Apple resources

Use first-party Apple sources for platform behavior, API availability, tools, and assets. This index was reviewed on 2026-09-28; Apple revises guidance and SDKs frequently, so recheck live pages for date-sensitive work.

## Core design sources

- [Apple Design](https://developer.apple.com/design/) — entry point for HIG, videos, tools, and resources.
- [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) — current cross-platform design guidance.
- [Getting started](https://developer.apple.com/design/human-interface-guidelines/getting-started) and [Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles).
- [Designing for iOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-ios).
- [Designing for iPadOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-ipados).
- [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos).
- [Apple Design Resources](https://developer.apple.com/design/resources/) — current UI kits, icon templates, color guides, fonts, and production resources. Use under Apple's current terms; link rather than copy.
- [UI Design Dos and Don'ts](https://developer.apple.com/design/tips/) — concise practical checks; the HIG remains the deeper authority.

## Asset and citation policy

- Link to Apple resources; summarize decision-relevant guidance in original language.
- Don't download or commit Apple templates, fonts, SF Symbols, UI kits, product bezels, screenshots, videos, or tool binaries into this skill.
- Review the license or usage terms presented with each resource before incorporating it into a product artifact.
- Use Apple trademarks, badges, and technology marks only under the current applicable guidelines.
